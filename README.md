# Оптовый подсчёт

Локальное приложение для учёта количества товаров в собранных заказах.

Проект разработан пользователем Shamrik специально для магазина HardSmoke.

## Запуск

Требуется Python 3. Запустите в этой папке:

```powershell
python server.py
```

Откройте http://localhost:8000

Заказы сохраняются в `orders.json` рядом с сервером. При работе в паре каждому сборщику начисляется `ceil(количество / 2)` позиций.
